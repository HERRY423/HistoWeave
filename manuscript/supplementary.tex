\section{Supplementary methods}

\subsection{Decision rule}

For a declared query task, HistoWeave performs the following ordered checks:
\begin{enumerate}
  \item reject references with an incompatible task, ground-truth kind, or
        \(K\) policy;
  \item verify the metric direction and retain method configurations rather
        than collapsing spatial-context settings;
  \item generate a target-free reference-neighbour ranking and compare its
        proxy score with the training-reference global method;
  \item require a source-hash-verified grouped held-out result with a matching
        task, truth kind, \(K\) policy, metric, panel, and split unit;
  \item intersect the ranked shortlist with the matched non-dominated Pareto
        set when a multi-objective table is supplied; and
  \item emit \texttt{personalised\_set}, \texttt{global\_default},
        \texttt{evidence\_required}, or \texttt{abstain}.
\end{enumerate}
The complete implementation is in
\texttt{src/histoweave/benchmark/decision.py}. Policy thresholds and every
check are serialized in the output card.

\subsection{Training, validation, and test separation}

The DLPFC benchmark contains five sections from one study
\citep{maynard2021}. It is an oracle-\(K\) development track and is not an
independent test. The five-dataset external panel is also oracle-\(K\); its
leave-one-dataset-out result is a diagnostic comparison with a training-fold
global method. The 20-query selective endpoint is grouped by study or
independent query unit. The six-section Wu breast-cancer cohort
\citep{wu2021} was absent from audited development sources and was executed
once under an in-repository locked rule, but it lacks an independent public
timestamp and uses oracle \(K\). It is therefore a negative stress test.
The non-oracle prospective-v2 protocol has no outcome data and remains
execution-blocked pending a public timestamp.

\subsection{Adversarial evidence corpus}

The 11 cases in Table~\ref{tab:audit} exercise the full
\texttt{build\_decision\_card} path. A valid dominated-candidate case is
expected to return a personalised set that excludes the dominated local
configuration; it is therefore a valid-evidence control, not an invalid case.
Rates reported in the paper use the eligible denominator for each endpoint.

  tests/test_evidence_audit.py \
  tests/test_submission_freeze_v3.py \

  tests/test_recommend.py

The P1 freeze binds the manuscript, supplement, cover letter, compliance
record, figure-generation script, figures, and underlying source tables by
SHA-256. It does not change the P0 scientific artefacts.

\section{AI-assisted preparation: mandatory author action}

This working draft received assistance from OpenAI Codex. The current
\textit{Bioinformatics} policy states that LLMs may assist with limited tasks
such as language correction, translation, anomaly detection, code, and
documentation when disclosed, but does not permit drafting a paper from a
prompt. Before submission, the human authors must substantively rewrite and
verify the manuscript, document only the final permitted use in the cover
letter and manuscript, or obtain written guidance from the Editorial Office.
This disclosure does not by itself make LLM-drafted text compliant.
