\subsection{Four-action decision rule}

For a declared query task \(\tau\) and evidence set \(\mathcal{E}\), the
ordered gate is:

\begin{enumerate}
  \item \textbf{Reject} references with incompatible task, ground-truth kind,
        undeclared or oracle \(K\) (when the query is non-oracle), missing
        metric direction, or unverified source hashes.
  \item Generate a target-free reference-neighbour ranking and compare its
        proxy to the \textbf{training-fold global} comparator (not only to
        random choice).
  \item If the local proxy does not beat the global comparator $\rightarrow$
        \texttt{global\_default}.
  \item If grouped held-out validation is missing or mismatched $\rightarrow$
        \texttt{evidence\_required}.
  \item If a matched Pareto table is supplied, retain only the intersection of
        the shortlist with the non-dominated set.
  \item If every hard gate passes $\rightarrow$ \texttt{personalised\_set};
        if no task-valid evidence remains $\rightarrow$ \texttt{abstain}.
\end{enumerate}

Default policy serialisation (changing any value creates a distinct policy):
shortlist size $\le 3$; minimum neighbour support $\ge 2$; rank-support
heuristic threshold $0.25$ (not a calibrated probability). Implementation:
\texttt{src/histoweave/benchmark/decision.py}.

\subsection{Training, validation, and test separation}

\begin{itemize}
  \item \textbf{T1 DLPFC} \citep{maynard2021}: five sections, one study;
        oracle-\(K\) development and sensitivity only.
  \item \textbf{T2 external panel}: five independent studies; oracle-\(K\);
        descriptive landscape only. It is excluded from selector training,
        cross-validation, external validation, and efficacy claims.
  \item \textbf{T3 selective}: twenty study-grouped queries; frozen selective
        regret--coverage endpoint.
  \item \textbf{T4 HER2ST} \citep{andersson2021}: primary external validation.
        Public registration (GitHub issue~19; server time
        2026-07-29T05:34:31Z) and protocol hash preceded outcome access.
        Non-oracle estimated \(K\); donor is the analysis unit; seven evaluable
        donors after locked exclusion of G2.
  \item \textbf{T5 synthetic}: disjoint development, calibration, signal-test,
        and null-test units; construct validity only, not biological external
        validation. The malformed v3 and failed v2.1 runs remain retained.
  \item \textbf{Secondary Wu} \citep{wu2021}: oracle-\(K\) one-shot stress
        test without independent public timestamp; not the non-oracle gate.
  \item \textbf{T4 CRC v4}: public issue~20 preceded data access. All 378
        attempts and seven \texttt{evidence\_required} actions were frozen before
        annotation download. The seven-patient nine-method same mask is complete;
        15 A120838 runtime skips are retained without imputation.
\end{itemize}
