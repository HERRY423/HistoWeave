\section*{Supplementary Note S1: Reproducibility}

All experiments can be reproduced from the repository root:

\begin{verbatim}
# DLPFC 20-method SOTA benchmark
python 5x15_spatial_aware/run_one_method.py \
    stagate checkpoints
python 5x15_spatial_aware/build_sota_and_merge.py \
    checkpoints

# External validation (5 datasets)
python benchmark_external_validation/\
    experiment_5x_external.py

# Oracle-K leakage (dual-track)
python non_oracle_k_sota/run_non_oracle_k_sota.py

# Independent test (Wu 2021)
python benchmark_external_validation/\
    independent_test_wu2021/run_independent_test.py

# Submission freeze verification
python submission_freeze_v2/reproduce_submission_freeze.py --check
\end{verbatim}

Environment locks for SOTA methods are in
\texttt{5x15\_spatial\_aware/env\_locks/}.
